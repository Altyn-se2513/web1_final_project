About Our Project

Our goal is to build an accessible, beautifully organized digital space for readers to discover, track, and review great books from around the world.

About the Team Member

Altyn Abdinurova

Role: Front-End Developer

I am a second-year Software Engineering student at Astana IT University (AITU). I designed and implemented the main layout, catalog structure, and global styling for the Book Collection platform.

More about Altyn: In her free time, she enjoys exploring new JavaScript libraries, contributing to open-source projects, and reading classic literature. She believes that a clean and accessible design can make a big difference in user experience.

Responsibilities Included:

  • HTML structure & semantic layout across all pages
  • Shared stylesheet creation and CSS selector configuration
  • Flexbox & Grid responsive layout design
  • Bootstrap 5 components, grid, utilities and forms
  • JavaScript form validation, popup, background switcher, live clock
  • Authentication simulation (localStorage)
  • Google Books API & Gutendex API integration
